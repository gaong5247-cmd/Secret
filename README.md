# RACA — RIVALS Adaptive Combat Agent (Experimental)

Android proof-of-concept for screen-only classical combat heuristics and online learning. **No pretrained model.** Motion regions are *not verified player detections*. APK is built through GitHub Actions.

No anti-cheat bypass, code injection, exploit scripts, or network interception. Screen capture and Accessibility input require explicit permission. Enable automatic input only where expressly authorized by the game operator. Private server access alone does not establish permission.

The first release is an experimental prototype, not a proven high-skill RIVALS bot. See implementation notes below after app code is committed.
